# Coherence evaluation set v1

60 groups (40 dev, 20 held out), grouped split v2.

**Labels: 0 of 60 confirmed.** This is a blind review worksheet. Draft labels and v4 verdicts remain in the JSONL and are intentionally omitted here.

Read [the annotation rubric](coherence-rubric-v2.md) before labeling. The held-out portion is a reserved regression set: these examples have already been inspected during development, so it is not an unseen test set.

Edit each JSONL row's `labels` with `coherent` (yes/partial/no), `title_faithful` (yes/no), `outliers` (child IDs), `note`, `reviewer`, and `rubric_version` (`v2`). Do not copy a draft into confirmed labels without reviewing the evidence. Uncertain examples should remain unconfirmed. Then run `python -m observatorio.eval_coherence report`.

Families join overlapping child sets and explicitly linked semantic/version variants; no family crosses the split. Draft values were not used to allocate splits. The set contains known failures, reference groups, and controls, not a random sample of usage.
The current grouped held-out set has no draft title-faithfulness negatives. It cannot establish detection of misleading titles; add fresh independently labeled families before claiming generalization on that dimension.

Baseline diagnostics are available separately with `report --diagnostics`; only confirmed labels are scored. Keep those diagnostics out of first-pass annotation.
